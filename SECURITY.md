# Политика безопасности

## Поддерживаемые версии

Поддерживается актуальная версия из ветки `main`.

## Сообщение об уязвимости

Не публикуйте секреты и данные об уязвимости в открытом Issue. Используйте приватный канал **Security → Report a vulnerability** в репозитории. В сообщении укажите шаги воспроизведения, возможное влияние и предлагаемый способ исправления.
