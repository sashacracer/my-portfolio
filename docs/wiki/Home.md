# Документация проекта «Портфолио»

Учебный статический сайт демонстрирует возможности GitHub Pages и связанные сервисы GitHub.

## Установка

1. Склонируйте репозиторий: `git clone https://github.com/sashacracer/my-portfolio.git`.
2. Откройте `index.html` в браузере.

## Структура

- `index.html` — семантическая разметка страницы;
- `styles.css` — адаптивное оформление;
- `script.js` — динамический год в подвале;
- `.github/` — шаблоны Issues, CI и Dependabot;
- `SECURITY.md` — политика безопасности.
