# Развёртывание

Сайт публикуется GitHub Pages из корня ветки `main`.

1. Изменения отправляются в `main`.
2. Workflow `CI` проверяет обязательные файлы и базовую структуру HTML.
3. После успешной проверки GitHub Pages обновляет сайт.

Публичный адрес: <https://sashacracer.github.io/my-portfolio/>
