# Архитектура

Проект не требует этапа сборки и внешних зависимостей: браузер загружает HTML, CSS и JavaScript напрямую.

## Принципы

- семантические секции и доступная навигация;
- адаптивная сетка для широких и мобильных экранов;
- минимальный JavaScript;
- автоматическая проверка структуры в GitHub Actions;
- обновление GitHub Actions через Dependabot.
