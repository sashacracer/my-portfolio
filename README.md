# Учебное портфолио

Репозиторий подготовлен для лабораторной работы № 5 по возможностям GitHub.

## Реализовано

- адаптивный статический сайт для GitHub Pages;
- Issues и шаблоны сообщений об ошибке/предложений;
- GitHub Actions для проверки HTML и структуры проекта;
- Wiki-документация;
- Dependabot и политика безопасности;
- Discussions и Gists.

Сайт: <https://sashacracer.github.io/my-portfolio/>

## Локальный запуск

Откройте `index.html` в браузере или запустите любой статический HTTP-сервер.
